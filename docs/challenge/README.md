# Описание челленджа: русский перевод

[MODIS_VIIRS_полный_перевод.docx](MODIS_VIIRS_полный_перевод.docx) — переданный командой неофициальный перевод описания задания **Harmonization of MODIS and VIIRS Hot Spots** и речи из поясняющего видео CONAE. Исходный файл сохранён без изменений.

В документе указано, что описание переведено по HTML-копии страницы, а речь — по автоматически сформированной английской расшифровке YouTube. Видеоряд отдельно не проверялся. Последний абзац с объяснением «потери десяти лет» является интерпретацией переводчика, а не частью выступления.

## Что учитываем в проекте

- Результат согласования — сопоставимый временной ряд, в котором различия сенсоров не определяют наблюдаемые тенденции и аномалии.
- Длинная история должна объединять MODIS с начала 2000-х и продолжение наблюдений VIIRS до текущего периода.
- Веб-приложение использует согласованные данные для календаря активности горения, выбора территории и периода, исторических сравнений и выгрузки результатов.
- В описании отдельно приведён пример сравнения текущего месяца с исторической медианой. Для неполных периодов нужны сопоставимые даты и явно указанные ограничения наблюдений.
- Произвольное рисование области, дополнительные визуализации и другие предложения из раздела «Что можно учесть дополнительно» не перечислены как обязательные условия.

## Связь с текущей реализацией

Полная исходная база команды покрывает 2000–2026 годы и все доступные платформы MODIS/VIIRS. Согласованный режим [MVP Оксаны](../../web/README.md) основан на [валидации за апрель–октябрь 2020–2025 годов](../sko-validation/README.md). Продление сопоставимого ряда на ранний MODIS/Terra, NOAA-21 и свежую NRT-часть требует отдельной проверки. Наличие длинного исходного архива само по себе эту проверку не заменяет.
