# NASA Space Apps: временной анализ

Главная страница — единое приложение с постоянной шапкой, атласом, анализом
территории и кейсами. При первом входе открыт мировой атлас с выбором области;
дальнейшие переходы сохраняют исследовательский контекст. В анализе доступны календарь
«годы × месяцы», недельная сезонная медиана с диапазоном, детали по неделям и
дням, карта месячных отклонений, ручное сравнение двух лет и их географии.
CSV и JSON сохраняют исходные значения, качество и признаки модельной оценки;
SVG экспортирует выбранную визуализацию. Название проекта и инфраструктуры —
NASA Space Apps / `nasa-space-apps`.

Атлас Оксаны встроен вместе с глобальными точками, слоями, исследованиями и
кейсами. `/atlas.html` и старые якоря остаются совместимыми ссылками.
Численные [глобальные матрицы](global-matrix.md) открываются отдельной вкладкой
анализа; старый фиксированный набор связей СКО подписан как исследование СКО.

## Запуск и данные

На сервере `deploy/compose.yml` поднимает web, analysis и существующий
global-fires. `/api/v1/` проксируется в analysis; `/api/fires/` остаётся
совместимым с атласом. Обновление проходит через действующую процедуру Komodo
`nasa-space-apps-deploy`; отдельный механизм публикации не нужен.

Analysis читает `/data` только для чтения и пишет производные данные в `/cache`.
Ему нужны `manifest.json`, `catalog.json`, годовые Parquet наблюдений и,
если он есть, согласованный live-tail. Облачные архивы на ноутбук не копируются.
Исходная граница СКО — `data/boundaries/north-kazakhstan.geojson`; остальные
области задаются прямоугольником в WGS84. Три зарубежных пресета — окна
исследования, а не точные административные границы.

Для локального API:

```bash
python3 -m pip install -r requirements-global.txt
python3 -c "import duckdb; c=duckdb.connect(); c.execute('INSTALL spatial')"
SPACEAPPS_DATA_DIR=/path/to/firms-global python3 -m api.server
```

UI и API обслуживаются с одного origin через nginx. Простая статическая
раздача `web/` показывает интерфейс, но сама не выполняет расчёты.

## Единицы и сезонное сравнение

Детекции фильтруются отдельно по продуктам: MODIS confidence ≥30, VIIRS
nominal/high. По умолчанию используются SP и type=0. Режим с NRT сохраняет
предварительный статус; неизвестный тип допускается только в этом режиме.
Спутники не складываются. Для каждого спутника отдельно считается число
различных ячеек равноплощадной сетки EPSG:6933 за сутки. Сумма за период —
ячейко-дни, а не число пожаров и не выгоревшая площадь.

Каждый месяц сравнивается с теми же числами месяца в базовых годах. Если в
целевом периоде есть известные пропуски, его точная маска дней переносится на
каждый исторический год. Год с неполной маской исключается. Оцениваемый год
не входит в собственную базу. Требуются минимум три других года и минимум
10 целевых дней либо весь выбранный короткий интервал. Неполные последние
сутки UTC доступны в исходном ряду, но не используются для заключения об
аномальности. Недельные профили используют ISO-годы и полные недели с семью
датами доступного глобального продукта; границы ISO-года явно указаны.

Карта отклонений использует тот же месячный интервал и базовые годы. Для
больших областей визуальная сетка укрупняется; сначала суммируются
ячейко-дни, затем вычисляются медианы и отклонения. Проценты не суммируются.
На дневном срезе доступна карта наблюдений; месячная карта отклонений не
выдаётся за дневную.

## Экспериментальное согласование

Для выбранной области, сетки и фильтров коэффициент переводит SP-активность
отдельной платформы в шкалу Aqua. Обучение использует указанные базовые годы;
проверка — только последующие годы на общих датах наличия SP. Показываются
исходная ошибка, ошибка коррекции, сезонная базовая модель и смещение.
Доступность режима определяется достаточным числом месяцев и активных
периодов, улучшением относительно исходного ряда, сравнением с сезонной
моделью и ограничением смещения. Это критерии прототипа, а не универсальный
научный стандарт.

Коррекция никогда не применяется к NRT-смешанному целевому месяцу. Для
согласованной исторической базы также требуется отсутствие NRT во всех
использованных датах её маски. Иначе `baseline_equivalent=null`, и интерфейс
не показывает скорректированное отклонение. Разброс коэффициента по выборкам
целых лет — частичная оценка вариации, не полная неопределённость результата.

Проверка относится к воспроизведению Aqua в этой области, на этой сетке и с
этими фильтрами. Она не доказывает полноту реальных пожаров и не переносится
автоматически на другую территорию. Ранние MODIS и новые платформы остаются
отдельными рядами, пока соответствующий переход не прошёл проверку.

## API и ограничения ресурсов

- `GET /api/v1/config`: пресеты, платформа, фактическая свежесть архива.
- `POST /api/v1/analyses`: `bbox`, `preset`, `start`, `end`, `baseline_start`,
  `baseline_end`, `grid_km`, `quality`, `daynight`; возвращает ID задачи.
- `GET /api/v1/analyses/{id}`: прогресс или результат.
- `GET /api/v1/analyses/{id}/export?format=csv|json`: выгрузка.
- `GET /api/v1/maps/{extract_id}?month=YYYY-MM&platform=...`: карта наблюдений;
  `day=YYYY-MM-DD` сужает до суток, `month=YYYY` выбирает ISO-год.
- `GET /api/v1/anomaly-map/{extract_id}?month=YYYY-MM&platform=...&baseline_start=YYYY&baseline_end=YYYY`:
  месячная карта отклонений.

Одна вычислительная задача и один запрос карты выполняются одновременно;
очередь ограничена восемью задачами. При занятости карта возвращает 429.
Ограничены площадь прямоугольника, размер тела запроса, память, число процессов
и объём кэша. Новые области сначала рассчитываются, повторный запрос читает
производный кэш. Источники удерживаются по inode под короткой блокировкой:
обновление архива не меняет снимок в середине анализа. Идентичность кэша
учитывает параметры, SHA256 исходников, исходную геометрию, список пропусков и
версию обработки; результат содержит происхождение и версию методики.

## Открытые научные ограничения

Глобальное наличие продукта не подтверждает пригодное наблюдение выбранной
ячейки. Локальные маски облачности/покрытия ещё не подключены: отсутствие
детекций не означает подтверждённое отсутствие огня. Проверка по независимым
ведомственным событиям США/Канады ещё не проведена. NOAA-21 в скачанном зеркале
имеет ранний пробел. Глобальная доступность интерфейса не означает доказанную
глобальную точность коррекции. Сезонность и необычная активность помогают
распределять внимание, но не являются прогнозом пожара или доказательством
причин горения.

## Проверки

`python3 -m unittest discover -s tests -v` включает воспроизводимые проверки
совпадения масок дат, NRT-ограничений, границ ISO-года и реальных пространственных
запросов DuckDB. В CI spatial устанавливается до тестов. Для работающего
приложения отдельно запускается `python3 tests/e2e_workbench.py --base-url URL`:
реальный браузер проверяет календарь, недельную кривую, карты, сравнение,
качество, выгрузки, мобильный экран, ошибки API и устаревшие ответы карты.
Статус независимой приёмки сохраняется в `workbench-features.json`.
