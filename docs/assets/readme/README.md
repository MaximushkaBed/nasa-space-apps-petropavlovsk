# README media

These assets illustrate the application in the [main README](../../../README.md) and the [Russian interface guide](../../../web/README.md).

## Application captures

Captured from [nasa.aican.cloud](https://nasa.aican.cloud/) on **16 November 2026**, using the English interface. Screenshots and the tour show the real application and existing results, rather than mockups or synthetic charts. They are fixed snapshots; use the dates and sources displayed in the application when interpreting them.

- `world.jpg`: the global atlas, daily view for 14 November 2026.
- `analysis.jpg`: North Kazakhstan analysis, with the 2022–2025 calendar, 2022–2024 reference years, a 10 km grid and an April 2025 selection.
- `atlas-calendar.jpg`: the prepared North Kazakhstan calendar beside its atlas view.
- `compare.jpg`: the year-comparison tab of the same regional analysis.
- `matrix.jpg`: the prepared North Kazakhstan factor matrix, with a selected pair of factors.
- `case.jpg`: the Kishkenekol before/after imagery case, using the dates displayed in the interface.
- `walkthrough.mp4` and `walkthrough.gif`: a silent tour of analysis, year comparison, atlas, factor matrix and the imagery comparison slider. Navigation waits are removed; playback is accelerated by a factor of 1.1. The GIF is the looping README preview; the MP4 is the higher-quality downloadable version.

The regional analysis capture uses the existing result `6a624cb4c3f4e9b2003d8c35ab31bfc9`; the prepared matrix uses `4e9255370106abdf3d75b8ff9ef80b03`. Capture requests reused available results and did not start a new regional analysis. Screenshots are illustrative, not an additional scientific validation.

Source attributions remain visible in the captured interface. For dataset and imagery provenance, see [Data Usage](../../../DATA_USAGE.md), the [atlas guide](../../../web/README.md) and the [matrix methodology](../../global-matrix.md). The application's datasets and third-party map/imagery sources retain their respective terms.

## Vector artwork

`cover.svg`, `badges.svg` and `pipeline.svg` are self-contained vector artwork created for this README. The globe and orbital paths are decorative illustrations, not measured satellite tracks or a data map. The badges describe the project's scope, languages and stack; they are not live test-status badges.
